原子轨道 · 波函数可视化
暗色 / 浅色学术版
基于用户提供的 index.html 改造

一、如何打开

1. 完整解压 ZIP。
2. 打开 orbital-academic/index.html，选择暗色或浅色。
3. 也可直接打开 dark/index.html 或 light/index.html。

两版均为自包含 HTML：样式、计算内核、着色器与交互脚本全部内嵌，不使用 CDN、在线字体、前端框架或外部运行依赖。正常计算不发出网络请求。模型说明中的 NIST 参考链接只有点击时才访问网络。

请保留 dark、light 两个文件夹的相对位置，这样顶部的主题切换可以正常工作。单独复制一个主题的 HTML 也能运行该版本，但无法跳转到另一个已移走的版本。

运行环境需要 JavaScript、Canvas 和 WebGL。高网格精度和大量采样点会增加显存、内存与计算量。若浏览器限制 Blob Worker，程序会自动改由主线程计算；也可以在文件 URL 后加 ?sync=1 显式使用主线程。

二、程序结构与原版分析

原程序不是静态轨道图片，而是一个完整的离线单页科学可视化程序：

• 物理内核：求值类氢库仑势的解析径向函数与归一化实球谐函数。
• 点云：径向逆累积分布采样，结合角向查表拒绝采样，生成 |ψ|² 概率样本。
• 等值面：利用径向与角向可分离性，通过数值积分及二分求解密度阈值，再在紧包围盒的均匀三维网格中提取三角面。
• 统计：径向概率分布、最概然半径、平均半径、90% 与 99% 球内概率半径，以及节点数。
• 渲染：WebGL 绘制点、曲面和参考线；Canvas 绘制曲线、尺度与文字。
• 计算调度：优先使用 Web Worker，并保留主线程后备与异步过期结果检查。

原版的主要呈现问题：

• 轨道、采样、显示、统计和物理说明堆叠在长侧栏内，需要反复滚动寻找常用操作。
• 发光按钮、渐变标题、透明面板和高饱和强调色较多，正文、图例和数据的重要程度不够明确。
• 径向图较小，坐标信息有限；物理数值容易被控制项淹没。
• 与当前模式无关的设置仍然可见，点云与等值面参数容易混淆。
• 界面的 m 实际用于实球谐基底，却标为磁量子数；概率百分比与真正的密度阈值也没有充分区分。
• 原始 WebGL 颜色和加性混合固定用于暗背景，直接换成浅色 CSS 会导致可视化不清楚。

三、界面改造

1. 信息布局

桌面采用三个清晰区域：三维轨道主视图、右侧分组控制栏、下方径向分析区。

控制栏分为“轨道”“显示”“模型说明”三个标签：
• 轨道：常用轨道、n / l / m / Z，以及当前模式的采样或等值面设置。
• 显示：点云强度与尺寸、渲染倍率、符号着色、节点、坐标、自动旋转、标准视角、状态链接。
• 模型说明：假设与约定、当前公式、读图说明、数值自检、参考定义。

手机端采用纵向布局，三维视图后紧接控制面板，再显示径向图与统计。标题、图例与三维画布分开排布，避免文字覆盖轨道主体。

2. 视觉风格

• 暗色版：石墨灰绘图区与低饱和控制栏，正瓣为暖红、负瓣为灰蓝。
• 浅色版：纸白控制栏与浅灰绘图区，使用更深的红、蓝保持对比。
• 统一细分隔线、小圆角、清晰字号与等宽数字；数学符号使用衬线字体。
• 去除装饰性发光和大面积彩色渐变；相位图例直接标记 ψ > 0 与 ψ < 0。
• 点云采用适合两主题的透明混合，曲面使用低高光材质。
• 默认展示 2p_z 点云，采用 z 轴向上的观察约定，便于看清正负两瓣。坐标圈位于 xy 平面。

3. 可读性与操作

• 径向图增加横纵刻度、轴单位、细参考线、最概然半径与平均半径标记。
• 将 a₀ 与 pm 数值分层排列；平均半径的理论值可通过悬停数值查看。
• 根据当前模式显示有效设置：点云不出现包络概率，等值面不出现粒子尺寸。
• 轨道按钮、模式按钮和标签页具有可访问名称、选中状态和键盘焦点。
• 增加缩放按钮、+x / +y / +z 标准视角、键盘操作以及可随时退出的专注视图。
• 主题切换保留轨道、核电荷、两种模式的设置、渲染倍率、语言及相机状态。

四、修正的物理表述与程序问题

1. 实球谐标签

“磁量子数 m（空间取向）”改为“实球谐分量 m”。在本程序中，m > 0 选择 cos(mφ) 分量，m < 0 选择 sin(|m|φ) 分量。非零分量是复球谐 ±|m| 的实线性组合，并非单独的 Lz 本征态。公式使用 Yᴿ 明示实基底。保留化学相位约定，例如 p_x 的正瓣朝向 +x。

2. 概率与密度阈值

等值面的滑块是包络内概率 P，不是 |ψ|² 的数值本身。其定义为：

  ρ = |ψ|²
  P = ∫_{ρ ≥ ρ₀} ρ dV

界面分别显示 P（百分比）与密度阈值 ρ₀（a₀⁻³）。“解析求解”“实际包含概率”改为与实现相符的数值求解、积分估计；该估计不代表三角网格零误差。

径向 90% / 99% 概率半径由球内积分定义，与一般非球形密度等值面的包络边界不是同一概念。

3. 核电荷公式拼接

原文件将字符串“2”与“Zr”直接拼接，Z=2 会出现“22r”。现改为先计算 2Z 再生成公式。例如 Z=2 时显示 4r，Z=6 时显示 12r。原来的数值波函数计算本身未受此显示错误影响。

4. 奇数网格原点归一化

原来的三维网格在精确原点对 s 轨道只取径向 R，遗漏了 Y₀₀。默认偶数网格不含原点，因而原版自检未覆盖此情况。现改为 R(0)Y₀₀，并增加 N=65、Z=1 与 Z=6 的回归检查。1s 原点密度应为 Z³/π，新增检查均通过。

5. 本地链接

原来的 location.origin + location.pathname 在 file:// 下会拼出“null”开头的地址。现用 URL 对象保存当前状态，并在剪贴板不可用时提供可手动复制的对话框。本地链接只适用于相同文件路径；将完整程序放到网站后，网站 URL 才可直接分享给他人。

6. 状态与错误处理

• 渲染前核对轨道标识，防止快速切换时旧几何短暂显示在新轨道标题下。
• 重建时清空旧统计与阈值显示，等待新数据。
• 专注按钮始终留在顶栏，可通过按钮或 Escape 退出。
• 导出会在同一任务中先重绘再读取 WebGL，避免空白图，并沿用当前主题。
• 缺少 WebGL 时给出明确的页面提示；计算错误显示可读的错误栏。

五、使用方法

基本操作

• 拖动三维图：旋转。
• 鼠标滚轮或 + / − 按钮：缩放。
• 双击三维图或“复位”：恢复默认视角。
• 触屏单指拖动：旋转；双指操作：缩放。
• 聚焦画布后：方向键旋转，+ / − 缩放，Home 复位。
• 标签页聚焦后：左右方向键切换，Home / End 到首尾标签。
• “专注视图”：隐藏控制栏与径向区；点击同一按钮或按 Escape 退出。

轨道范围

• 主量子数：n = 1…6。
• 角量子数：l = 0…n−1，对应 s、p、d、f、g、h。
• 实球谐分量：m = −l…+l。
• 核电荷数：Z = 1…6，对应 H、He⁺、Li²⁺、Be³⁺、B⁴⁺、C⁵⁺。

图像导出

“导出 PNG”输出当前三维视图，并带有轨道名、n / l / m / Z、显示模式、点数或包络概率、正负符号图例（开启时）、尺度（开启时）、径向摘要及模型假设。导出不包含控制面板。程序正在重建时请等待完成后导出。

状态链接

“显示 → 复制当前视图链接”保存当前参数。主要 URL 参数为：

  n, l, m, Z        轨道与核电荷
  mode             points 或 iso
  N                点数
  iso              包络概率百分比（1…99）
  isoN             网格边长点数
  bright, pt       点云强度、粒子尺寸
  quality          渲染倍率
  phase, nodes     符号着色、节点开关
  grid, spin       坐标尺度、自动旋转开关
  lang             zh 或 en
  az, el, zoom     相机参数
  sync=1           强制主线程计算

所有物理参数仍由原有范围约束保护。界面的三个等值面精度为 128³、176³、224³；原程序的 URL 自定义网格能力保留。过高分辨率会明显增加内存与计算时间。

六、验证结果与边界

实际验证环境：Chromium 153.0.8010.0、WebGL 1.0、ANGLE / SwiftShader 软件渲染，使用 file:// 打开，设备像素比为 1。已对最终布局和导出改动追加检查。

• 最终两主题计算内核一致。
• 数值自检：69 / 69 通过，包括原有 67 项和新增 2 项奇数网格检查。
• 已完成 23 项功能检查，涵盖点云、轨道参数、核电荷、高量子数组合、等值面、辅助图层、中英文、专注与快速连续切换。
• PNG 的暗、浅背景与有效图像内容已验证。
• 主题切换后的状态一致；本地链接及手动复制后备可用。
• 检查多个桌面、平板和手机视口，包括 1440、1280、900、768、390、320 像素宽度，覆盖中文和英文。
• 正常启动与操作没有请求外部网络资源。

数值自检使用预设容差，并不消除有限采样、角向查表、网格离散化、三角化与浮点舍入误差。可视化保留非相对论、无限核质量的单电子模型；不包含电子相互作用、精细结构、外场或时间演化。自动旋转只改变相机，点并不表示电子轨迹。

当前显示的 E_n = −13.605693… Z²/n² eV 与无限核质量模型一致。它不是对真实氢原子约 −13.598 eV 电离能的实验重现。壳层简并度 2n² 包含自旋，不是当前单个实轨道的简并度。

只有上述 Chromium 环境经过实际自动化验证；未声称对所有浏览器、真实手机触控设备或硬件显卡完成穷举测试。
